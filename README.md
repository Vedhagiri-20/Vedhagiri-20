# Featured Engineering Project

## Secure Flow

### Enterprise Loan Workflow & Approval Platform

[![Live](https://img.shields.io/badge/Live_Demo-Open_Secure_Flow-C9A55C?style=for-the-badge)](https://secureflow-enterprise.onrender.com)
[![Repository](https://img.shields.io/badge/GitHub-Source_Code-181717?style=for-the-badge\&logo=github)](https://github.com/Vedhagiri-20/secureflow-enterprise-platform)
[![Release](https://img.shields.io/badge/Release-v1.0.1-0C2B40?style=for-the-badge)](https://github.com/Vedhagiri-20/secureflow-enterprise-platform/releases/tag/v1.0.1)

Secure Flow is a production-deployed full-stack application that models an enterprise loan workflow across **customers, lending employees, managers, and administrators**.

I built the project end-to-end — application workflow, backend APIs, authentication and authorization, relational data model, role-specific interfaces, reporting, audit visibility, logging, Docker deployment, managed PostgreSQL, and production documentation.

### Business Workflow

```text
Customer
   ↓
Eligibility Assessment
   ↓
Loan Application
   ↓
Employee Review
   ↓
Manager Decision
   ↓
Approved / Rejected
   ↓
Customer Status
   ↓
Audit & Reporting
```

### Engineering Highlights

- Designed and built a multi-role enterprise workflow spanning Customer, Employee, Manager, and Administrator experiences
- Developed secure REST APIs using Java 21, Spring Boot, Spring Security, JWT authentication, BCrypt, and Role-Based Access Control
- Designed the PostgreSQL data model and workflow lifecycle using JPA/Hibernate with audit and reporting support
- Built role-specific frontend experiences for application processing, approval workflows, administration, and reporting
- Implemented production observability with frontend diagnostics, backend request/error logging, and centralized Render logs
- Containerized and deployed the full application using Docker, Render, and Neon PostgreSQL with production documentation and release management
