# 🚀 Flagship Project

## Secure Flow — Enterprise Loan Workflow & Approval Platform

**Live Application:**  
https://secureflow-enterprise.onrender.com

**GitHub Repository:**  
https://github.com/Vedhagiri-20/secureflow-enterprise-platform

Secure Flow is a deployed full-stack workflow platform that models an end-to-end enterprise loan-processing lifecycle across **customers, employees, managers, and administrators**.

The platform demonstrates secure application design, multi-role workflows, relational data modeling, REST APIs, auditability, reporting, containerization, and cloud deployment.

### Core Workflow

```text
Customer Registration
        ↓
JWT Authentication
        ↓
Eligibility Assessment
        ↓
Loan Application
        ↓
Employee Review
        ↓
Manager Decision
        ↓
Approved / Rejected
        ↓
Customer Status
        ↓
Audit & Reporting
